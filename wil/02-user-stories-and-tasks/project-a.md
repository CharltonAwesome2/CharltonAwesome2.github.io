# Project A: Product Catalogue Application

## Overview

Development of a web-based application for browsing and managing a product catalogue, including customer-facing functionality and administrative operations.

## User stories and tasks

### A-01: Browse products

**User story:** As a customer, I want to browse available products so that I can discover what is offered.

**Tasks:**
- Design the product data structures.
- Implement catalogue retrieval through backend services.
- Display products in the application.
- Test catalogue functionality.

**Status:** Completed.

### A-02: Search and filter products

**User story:** As a customer, I want to search and filter products so that I can find products matching my requirements.

**Tasks:**
- Identify searchable product attributes.
- Implement search functionality.
- Implement filtering options.
- Connect frontend functionality to backend services.
- Test searches and filter combinations.

**Status:** Completed.

### A-03: View product details and variations

**User story:** As a customer, I want to view product information and available variations so that I can make informed selections.

**Tasks:**
- Implement product-detail functionality.
- Develop backend operations for retrieving product information.
- Display relevant product details.
- Implement variation handling.
- Test product and variation relationships.

**Status:** Completed.

### A-04: Manage a cart and wishlist

**User story:** As a customer, I want to manage a shopping cart and wishlist so that I can keep track of products I intend to purchase or revisit.

**Tasks:**
- Implement cart functionality.
- Implement wishlist functionality.
- Connect frontend components to backend services.
- Test adding, retrieving and removing products.

**Status:** Completed.

### A-05: Manage inventory and orders

**User story:** As an administrator, I want to manage inventory and access order information so that I can oversee application operations.

**Tasks:**
- Develop inventory functionality.
- Implement order-related operations.
- Connect administrative components to backend services.
- Test inventory and order operations.

**Status:** Completed.

### A-06: Manage user accounts and authentication

**User story:** As an administrator, I want user accounts and authentication to be managed so that access to the application can be controlled.

**Tasks:**
- Implement authentication functionality.
- Develop registration functionality.
- Implement employee-management functionality.
- Test account and authentication operations.

**Status:** Partially completed.

**Outstanding:** Authentication was partially implemented. Registration and employee-management functionality had not been started when development stopped.

## Project outcome

Development was discontinued following a stakeholder decision. Several major application areas had been implemented, but outstanding functionality remained.
