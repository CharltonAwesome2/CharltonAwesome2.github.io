# Project B: Corporate Website

## Overview

Development of a corporate website presenting organisational information through two main sections, including information about an associated organisation.

## User stories and tasks

### B-01: Access organisational information

**User story:** As a website visitor, I want to access organisational information so that I can understand the organisation and its activities.

**Tasks:**
- Review supplied organisational information.
- Plan the website structure and navigation.
- Develop the required website sections.
- Implement content and navigation.
- Test the presentation of information.

**Status:** Completed.

### B-02: Access the website on different devices

**User story:** As a website visitor, I want the website to adapt to different screen sizes so that I can access it using different devices.

**Tasks:**
- Implement responsive layouts.
- Adapt navigation for different screen sizes.
- Test different viewport sizes.
- Correct layout and usability issues.

**Status:** Completed.

### B-03: Contact the organisation

**User story:** As a website visitor, I want to access contact functionality so that I can make an enquiry.

**Tasks:**
- Implement contact functionality.
- Include relevant contact information.
- Test the contact process.
- Correct identified issues.

**Status:** Completed.

### B-04: Update website content

**User story:** As a stakeholder, I want website content to be updated so that the information presented remains accurate and relevant.

**Tasks:**
- Review stakeholder feedback.
- Identify requested content and presentation changes.
- Update relevant content and sections.
- Replace or update requested imagery.
- Review the completed changes.

**Status:** Completed.

## Project outcome

The website was completed, deployed and accepted following stakeholder review and requested updates.
