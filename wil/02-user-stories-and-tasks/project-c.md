# Project C: University Information System

## Overview

Development of a university information system supporting academic and administrative processes, including user management, academic structures, student records, scheduling, attendance and communication.

## User stories and tasks

### C-01: Manage users and access

**User story:** As an administrator, I want to manage users, roles and permissions so that access to system functionality can be controlled.

**Tasks:**
- Implement user-management functionality.
- Develop authentication and authorisation.
- Implement role-based access control.
- Implement permission hierarchies and feature controls.
- Test access restrictions and user operations.

**Status:** Completed.

### C-02: Manage academic structures

**User story:** As an administrator, I want to manage academic structures so that the system can represent the institution's organisational and academic environment.

**Tasks:**
- Design and implement academic data structures.
- Manage campuses, buildings, faculties and departments.
- Implement course and module management.
- Manage academic offerings and related information.
- Implement relevant staff assignments.

**Status:** Completed.

### C-03: Manage student information and progress

**User story:** As an authorised staff member, I want to access student information and academic progress so that student records can be maintained.

**Tasks:**
- Implement student-related functionality.
- Develop student progress tracking.
- Implement relevant academic record operations.
- Test student information and progress functionality.

**Status:** Completed.

### C-04: Manage enrolment

**User story:** As an authorised staff member, I want to manage student enrolments so that students can be associated with the appropriate courses and modules.

**Tasks:**
- Develop course enrolment functionality.
- Implement module enrolment operations.
- Connect enrolment functionality to the relevant academic structures.
- Test enrolment operations.

**Status:** Incomplete.

### C-05: Manage schedules and attendance

**User story:** As a lecturer or authorised staff member, I want to manage class schedules and record attendance so that academic activities and student attendance can be monitored.

**Tasks:**
- Implement timetable functionality.
- Manage venues and scheduling information.
- Develop class and attendance-recording functionality.
- Implement attendance types and statuses.
- Prevent duplicate attendance records.
- Develop attendance reporting.
- Test scheduling and attendance operations.

**Status:** Completed.

### C-06: Manage communication

**User story:** As an authorised staff member, I want to communicate with users through email and SMS so that important information can be distributed.

**Tasks:**
- Implement email functionality.
- Implement SMS functionality.
- Develop communication templates and triggers.
- Support individual and group communications.
- Implement communication logging.
- Test message delivery and logging.

**Status:** Completed.

### C-07: Generate administrative reports

**User story:** As an administrator, I want to generate administrative and academic reports so that relevant institutional information can be reviewed.

**Tasks:**
- Identify reporting requirements.
- Implement reporting functionality.
- Develop the required report outputs.
- Test report generation.

**Status:** Completed.

### C-08: Provide in-app notifications

**User story:** As a system user, I want to receive in-app notifications so that I can be informed of relevant updates.

**Tasks:**
- Identify notification requirements.
- Develop notification functionality.
- Integrate notifications with the relevant system operations.
- Test notification delivery and retrieval.

**Status:** Incomplete.

### C-09: Manage examination-related functionality

**User story:** As an authorised staff member, I want to manage examination-related information so that examination activities can be administered.

**Tasks:**
- Develop examination-related pages.
- Implement the required frontend functionality.
- Integrate the pages with relevant backend services.
- Test the completed functionality.

**Status:** Incomplete.

### C-10: Manage student payments and graduation eligibility

**User story:** As an administrator, I want to manage student payment information and graduation eligibility so that these aspects of the student lifecycle can be administered.

**Tasks:**
- Identify payment-management requirements.
- Plan student payment functionality.
- Identify graduation eligibility requirements.
- Plan the required academic checks and records.

**Status:** Planned, not implemented.

## Project outcome

The system contains implemented functionality across several academic and administrative areas. Enrolment, in-app notifications and examination-related functionality remained incomplete. Student payments and graduation eligibility were planned but had not been implemented.

Development was paused while awaiting further feedback.
